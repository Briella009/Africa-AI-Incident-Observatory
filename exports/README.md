# Generated interoperability exports

This directory is the default destination for AAIO's derived interoperability artefacts.

Generate them with:

```bash
python scripts/export_interoperability.py
```

Outputs:

- `aaio-interoperability-v1.json` — deterministic semantic alignment export
- `aaio-interoperability-v1.sha256` — SHA-256 manifest for the JSON file

The generated files are ignored by Git. This is intentional: `data/incidents.csv` and `mapping/interoperability-map-v1.json` are the authoritative inputs, and the export can be regenerated byte-for-byte from them.

For a temporary export in CI or analysis workflows:

```bash
python scripts/export_interoperability.py \
  --output /tmp/aaio-interoperability-v1.json \
  --sha-output /tmp/aaio-interoperability-v1.sha256
```

See [`docs/interoperability.md`](../docs/interoperability.md) for mapping semantics, limitations, and the no-inference policy.
