# Ethics and Safety

## Public evidence only
AAIO uses public sources. Do not submit private personal data, credentials, leaked datasets or identifying information about private victims unless it is essential, lawful, already responsibly public and proportionate to the research purpose.

## No amplification by reproduction
The dataset describes harmful synthetic media; it does not mirror deceptive videos/images by default. Source links are preferred over redistributing manipulative media.

## Preserve uncertainty
AAIO does not infer creators, sponsors, intent, model identity or state involvement when the evidence does not support those claims.

## Avoid detector-only claims
AI-content detectors can be wrong. Detector output alone is not sufficient for a core record unless corroborated by additional evidence.

## Minimise harm
Descriptions should be sufficient for research without becoming instructions for fraud, evasion, harassment or manipulation.

## Corrections
Good incident datasets must be correctable. Submit a Data correction issue with source evidence when a record is wrong, incomplete or outdated.
