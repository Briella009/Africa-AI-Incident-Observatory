# 60-second demo video script

## 0-8 seconds — problem

Show the AAIO README and dashboard link.

Narration:

> "AI incidents affecting African people and institutions are often scattered across reports, languages, and jurisdictions. AAIO turns that fragmented reporting into source-traceable structured evidence."

## 8-25 seconds — explore

Open the live dashboard and select one core incident.

Show the incident summary, country, category, evidence confidence, severity, and source links.

Narration:

> "Each core record preserves provenance, separates evidence confidence from severity, and keeps uncertainty visible instead of forcing weak claims."

## 25-42 seconds — inspect the data

Show `data/incidents.csv`, the data dictionary, or dataset card.

Narration:

> "The same records are available as machine-readable open data with a documented schema, dataset card, interoperability notes, and release provenance."

## 42-52 seconds — reproducibility

Show the DOI badge and validation workflow.

Narration:

> "Versioned research snapshots are archived with DOI-backed provenance, while automated validation checks the evolving public dataset."

## 52-60 seconds — call to action

Narration:

> "Explore the dashboard, cite the dataset if you use it, star the repository to follow releases, fork it for analysis, or contribute evidence-quality and tooling improvements."

## Recording notes

- Use only public evidence already present in AAIO.
- Do not imply endorsement by AIID, OECD, NIST, the African Union, or any government.
- Do not describe DOI minting as independent adoption or citation.
